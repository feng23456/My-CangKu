# Auto Labeling with LLM (大模型自动化打标签)

## 📖 项目简介 (Project Overview)
本项目为求职笔试作品。旨在探索和验证大语言模型（LLM）在自动化数据标注（Auto Labeling）任务中的可行性。
我选择了一个包含正面和负面评价的公开文本数据集（模拟影评），通过调用大模型 API 进行情感分类打标签，并对比了模型与人工标注的差异。

## 🛠️ 技术与方法 (Model & Method)
- **使用模型**：大语言模型（如通义千问/Qwen 或 GPT 系列）。
- **调用方式**：通过 Python 调用 API 进行推理。
- **Prompt 设计**：设计了一套限制性提示词，要求模型仅输出“正面”或“负面”的单一标签，以降低输出格式的噪声。

## 📂 文件说明 (Files)
- `demo_code.py`：实现数据读取、模型调用与标签输出的核心代码。
- `data.csv`：输入测试的原始文本数据（包含 10 条无标签样本）。
- `result.csv`：经过大模型自动标注后的输出结果。
- `report.md`：详细的英文评估报告，包含结果分析、人机对比及改进思路。

## 📊 核心结论 (Result Analysis Summary)
- **表现优良**：模型在语义清晰、直白的评价上准确率极高，且速度极快、一致性极强。
- **表现受限**：面对反讽（如“拍得真好，让我睡了两个小时”）或隐含上下文情感的文本，模型偶尔会误判。
- **改进方向**：建议引入 Few-shot Prompt（少样本提示）或采用多模型投票机制来提高复杂语义的鲁棒性。
