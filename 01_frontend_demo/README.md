# Frontend Demo (前端设计稿还原)

## 📖 项目简介
本项目为求职笔试作品。根据 Figma 提供的交互设计稿，使用纯 HTML 与 CSS 进行网页界面的高保真响应式还原，呈现了包含上传组件与拖拽区域的 UI 界面。

## 🛠️ 核心技术
- **HTML5**：采用语义化标签（`main`, `section`, `button`）搭建清晰的 DOM 结构。
- **CSS3**：使用 Flexbox 布局、阴影、边框、色彩搭配实现精准还原。
- **SVG**：内联绘制轻量级占位插画，无需依赖外部图片资源。

## 📂 文件说明
- `index.html`：包含完整 HTML 结构与内部 CSS 样式的单文件代码。

## 🚀 快速启动
直接将 `index.html` 文件拖入浏览器（Chrome/Edge 等）双击打开即可查看效果。
